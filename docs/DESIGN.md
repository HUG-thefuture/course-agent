# CourseAgent 设计与迭代记录

本文档是开发过程的留痕，按需求要求的流程记录：**思考 → 出具计划 → 审查计划 → 按计划开发 → 测试 →（发现问题回到最初步骤循环）**。

## 1. 需求原文归纳

1. 输入课程链接与密码，自动整理直播课知识点、生成配套习题与关键节点
2. 依托本地大模型与网络数据，可通过 API 接入外部大模型
3. 工作流：思考 → 计划 → 审查计划 →（通过）按计划开发 /（不通过）返回修改 → 测试 →（发现问题）循环直至无明显问题
4. 无逻辑错误、无内存泄漏等常见编码问题，功能可用
5. 对助手进行"训练"以达到要求
6. 新建文件夹存放，提交到 git 仓库

## 2. 思考阶段（方案取舍）

| 问题 | 分析 | 结论 |
| --- | --- | --- |
| "直播课链接+密码"如何落地？ | 各平台加密机制互不相同，通用爬取不现实 | 支持字幕/文稿/转写JSON/PDF/音视频/可访问URL 六类输入；URL 密码走通用约定；平台适配留扩展点（ingest 层），如实写进 README |
| 本地模型 + 外部 API 如何统一？ | 主流服务全部兼容 OpenAI Chat Completions 协议 | 单一 `OpenAICompatClient` 覆盖 Ollama/LM Studio/DeepSeek 等；`Router` 做本地优先、失败回落 |
| 工作流如何不变成死循环？ | 模型输出不可控，必须保证终止 | 外层 `max_attempts=3` + 内部重试上限，所有失败路径有出口 |
| "训练"如何诚实落地？ | 本地权重微调成本高、不可复现 | 范例沉淀+相似度召回（少样本自改进）+ 评估循环留痕 + `export-sft` 导出 Alpaca 格式供真正 LoRA 微调 |
| 依赖策略 | 用户机器环境各异 | 核心零第三方依赖（纯标准库），whisper/pypdf 为可选增强 |
| 语言/技术栈 | 用户 Python 有基础，LLM 生态 Python 最成熟 | Python 3.10+，dataclass + sqlite3 + argparse + unittest |

## 3. 计划阶段（模块拆分）

```
ingest(加载/分块) → pipeline{think→plan→review→execute→test} → outputs(5类产物)
                     ↑ llm(mock/openai-compat/router)          ↑ memory(sqlite 范例/反馈)
```

关键决策：
- 分块由**代码确定性**完成（保留时间戳边界），模型只负责语义组织 → 结构永远可校验
- 计划必须是严格 JSON，代码硬校验"块覆盖完整性"，模型审查做语义补充
- 产物生成与质检分离：executor 产出，tester 用代码校验 + 忠实度抽查双重把关
- MockLLM 作为一等公民：让整条管线可离线测试、可零配置演示

## 5. 测试结论

- **单元测试**：83 个用例全部通过（`python -m unittest discover -s tests`），全程离线
- **离线演示**：`python main.py demo` 全流程通过，产物完整
- **真实模型冒烟**：本机 Ollama + qwen3:8b，对 1724 字直播文稿端到端一次通过，
  质检得分 100、忠实度 100%，知识点/习题内容与原文核对无编造

## 6. 迭代二：腾讯会议适配（2026-09-28）

用户反馈课程通过腾讯会议进行，重新走了一遍 思考→计划→审查→测试：

**思考**：调研确认（[官方帮助中心](https://meeting.tencent.com/support/topic/2070/index.html)、
[CSDN 抓流原理](https://blog.csdn.net/2501_93364350/article/details/161460745)）：
回放分享链接形如 `share.html?record_id=xxx&access_code=xxx`，页面 JS 渲染，播放流是
带时效 token 的 HLS（m3u8）；直播中实时字幕无学员侧程序接口。

**计划**：三条接入路径（回放页官方下载 mp4 / 分享链接+提取码全自动+引导抓流兜底 /
转写文稿）；下载优先 ffmpeg（检测到本机 8.1.2），无 ffmpeg 走纯标准库 HLS
（滑动窗口并发，AES-128 需 pycryptodome）；转写用 faster-whisper（已安装并预取
small 模型，HF 默认走国内镜像）。

**审查发现并修复**：
- `_hls_python_download` 中残留的全局 `from Crypto import` 会让无加密流也强依赖
  pycryptodome —— 移除，改为仅在检测到加密时才要求；
- `cmd_fetch` 对本地 Windows 路径误调用 `classify_url`，`C:\...mp4` 被 urlparse
  误判为媒体 URL 触发 ffmpeg —— 先判 `^https?://` 再分类；
- 下载函数不创建父目录、cli 的 `DownloadError` 导入路径错误 —— 均修复。

**测试**：106 个用例全绿（新增 23 个：HLS 解析/主清单选择/加密识别/本地 HTTP
服务器端到端下载/分享页扫描/提取码合并/引导话术/fetch 命令）。
用假 record_id 实测引导路径：腾讯服务器返回 404 后优雅降级为分步指引。

## 7. 迭代三：真实链接实战（2026-09-28，用户提供《88、作业讲评》回放）

用户提供短链 `meeting.tencent.com/crm/2ydzBry00f` + 提取码，走完一次真实闭环：

**调研修正**：短链直接 200 返回 Next.js 壳页（无 record_id），JS 跳转到 `/cw/`；
数据全部由客户端经网关签名接口拉取，纯服务端抓取不可行。改用受控浏览器打开
分享页 → 输入提取码 → 从 `performance` 资源条目捕获页面自己发起的接口调用。

**关键发现**：
- 转写接口 `wemeet-cloudrecording-webapi/v1/minutes/detail`（分页，毫秒时间戳，
  按句分词，段带发言人）在浏览器上下文重放即可取全量数据（limit=1000 一次拉 104 段）；
- 视频为双路 MP4 直链（screen=屏幕共享 / speaker=摄像头，带时效 token）；
- 腾讯自带 `get-critical-node` 接口，但实测仅返回停录事件，价值有限。

**落地**：新增 `tools/convert_tencent_minutes.py`（纪要 JSON -> 管线输入格式），
`is_tencent_share` 支持 `/crm/`、`/cw/` 短链，引导话术改为"逐字稿优先"双路径。
88 分钟 / 2.6 万字真实逐字稿已送入完整管线（qwen3:8b）生成笔记与习题。

**测试**：110 个用例全绿（+4：短链识别、转换器四则）。

## 8. 迭代四：编程实战题（2026-09-28，用户反馈）

用户要求习题里增加编程动手练习，新增 `coding_practice` 题型：

- **独立生成调用**（TASK: CODING 提示词）：与常规习题分开出题，避免输出过长被
  max_tokens 截断；每节 1~2 道，含 question / starter_code（骨架+TODO）/
  answer（参考实现）/ hints / check_points / explanation / difficulty；
- **失败降级**：编程题是增强功能，生成失败仅告警跳过，不影响主流程产物
  （MockLLM(fail_coding=99) 全坏输出时管线照常通过，有测试保障）；
- **源内容无关时输出空数组**：纯理论章节不强凑编程题；
- **渲染**：题目区给任务+起始代码+提示，文末给参考实现（代码块）+验收要点清单。

测试 115 个全绿（+4：字段校验、证据可见、降级路径、渲染断言）。

## 9. 迭代五：批量 / 视频 / 不完整课程（2026-09-28，用户三项新需求）

1. **批量识别**：新增 `batch` 命令 + `batch.py`。输入支持目录（自动扫描音视频/
   字幕/文稿）、`.list` 行清单（`链接|提取码|标题`）、`.json` 清单、URL 与单文件
   混合。逐项隔离（单项失败不断批）、断点续跑（有产物即跳过，--force 重跑）、
   转写缓存（路径+大小+mtime 键，重复处理秒级）、共享记忆库、batch_report.json 汇总。
2. **视频 → 编程试题**：三通道——faster-whisper 语音转写；ffmpeg 场景检测提取
   屏幕关键帧存档至产物 frames/（静态画面逐级放宽采样兜底）；可选视觉模型
   （config.vision，如 qwen2.5vl）把帧"看"成屏幕演示记录，按时间归入对应章节
   注入编程题提示词。视觉未配置时自动降级。
3. **不完整课程**：素材低于 `pipeline.partial_chars`（默认 3000 字）自动按片段
   处理，think/plan 提示词注入"按现有内容组织，不假设缺失部分"。

**审查发现并修复**：目录扫描漏掉文稿扩展名；单个 .txt 文件与清单文件的歧义
（定为：显式给出的 .txt/.md 是课程，清单用 .list/.json）；.list 行被包装时
丢失 `|` 字段；帧兜底采样间隔对短视频过稀（改逐级放宽 60s→10s→2s）。

**端到端验证**：PowerShell SAPI 中文 TTS（Huihui）合成 96 秒微课视频 →
`batch` 目录输入 → whisper 真实转写（39s，21 段）→ 自动判定不完整课程 →
帧提取 2 张 → qwen3:8b 管线 100 分 → 编程题内容与音频所述完全对应。

**测试**：135 个全绿（+20：清单解析、批量隔离/续跑/缓存、帧提取真实 ffmpeg
集成、视觉描述、多图 payload、partial 检测）。
